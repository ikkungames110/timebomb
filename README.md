# タイムボム

正体隠匿ゲーム「タイムボム」を、スマホのブラウザで P2P 対戦できる Web アプリです（4〜8人）。

## 遊び方
- ホストが「部屋をつくる」→ 5文字の部屋コード（または招待リンク）を共有
- 他の人は「参加」でコードを入力、またはリンクを開く
- ホストが開始すると役職（ボム処理班 / ボマー団）と導線カード5枚が配られる
- 「👁 見る」で自分の役職と手札の内訳を確認（位置は自分にも分からない）。「宣言」で解除枚数・爆弾の有無を表明できる（ウソOK）
- ニッパー ✂️ を持つ人が自分以外のカードを選んで「切る」。ニッパーは切られた人へ
- 人数分切ったらラウンド終了。残りを集めて配り直し（4→3→2枚）

| 人数 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|
| ボム処理班 | 3 | 3 | 4 | 5 | 5 |
| ボマー団 | 2 | 2 | 2 | 3 | 3 |

役職カードは表の枚数を混ぜて配り、4人・7人では1枚余って伏せられます。導線カードは 解除＝人数分・爆弾1枚・残り安全（計 人数×5枚）。

- **ボム処理班の勝利**: 解除カードをすべて切る
- **ボマー団の勝利**: 爆弾が切られる、または4ラウンド終了までに解除しきれない

## 開発
```
npm install
npm run dev     # スマホからは http://<PCのIP>:5173
npm run build   # dist/ を静的ホスティングへ
npm test
```

## 通信について
- ホスト端末が進行役となり、各プレイヤーと WebRTC で直接つながります（シグナリングのみ PeerJS 公開ブローカー）。
- 他人の役職・手札の中身はゲーム終了までホスト以外の端末には送られません。
- ホストがブラウザを閉じると部屋は解散します。ゲストは通信が切れても自動で再接続し、同じ席に戻れます。
- 厳しい NAT 環境では `VITE_TURN_URL` / `VITE_TURN_USER` / `VITE_TURN_PASS` を設定して TURN を使ってください。

## デプロイ
Cloudflare Pages（プロジェクト名 `timebomb`）。プロジェクト外のディレクトリから実行します。
```
npm run build && (cd /tmp && npx wrangler pages deploy "$OLDPWD/dist" --project-name timebomb --branch main)
```
